# Roadmap

## v0.1 (included)
- In-memory prototype, CLI, FastAPI, baseline tests, synthetic task generator.

## v0.2
- Storage interfaces and PostgreSQL persistence with migrations.
- Embedding-based retrieval behind an optional adapter.
- Event provenance, export/import, append-only audit log.
- Baseline comparison: recency-only vs Memory Gravity vs lexical retrieval.

## v0.3
- Multi-agent roles (analyst, skeptic, ethicist, synthesizer).
- Better planner with tool adapters and bounded execution.
- Controlled world-state transitions and relationship graph.

## v0.4
- Unity/Godot integration example, event schema, asynchronous runtime.
- Observability dashboard and latency/cost tracking.

## v1.0 criteria
- Preregistered benchmark protocol, baseline comparisons, confidence intervals, ablation studies, documented limitations, and independent reproduction.
