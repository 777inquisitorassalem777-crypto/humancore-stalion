# Проверки и интерпретация

Unit-тесты проверяют allowlist, некорректные числа, аварийный стоп, ограничение
скорости, препятствие, батарею, целостность цепочки, интеграцию veto,
кинематику и воспроизводимость сценариев.

Доля block — частота срабатывания правил на заданном распределении сценариев,
а не точность распознавания опасности. Среднее Pneuma — статистика рекуррентной
численной модели, не показатель одушевлённости. Coherence вычисляется из
отклонения от текущего целевого значения, а не из анализа логики рассуждений.

ROS2, Gazebo, Docker и GitHub Actions в текущей среде не запускались.
ROS2 и Gazebo не включены: пакет не управляет физическим оборудованием.
