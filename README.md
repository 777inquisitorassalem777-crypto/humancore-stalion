# HUMANCORE / STALION — research simulation

Полный исходный код самостоятельной исследовательской реализации, версия 0.1.0.
Это новая согласованная реализация по мотивам приложенного материала, а не
дословное восстановление всех исторических версий.

## Границы

Только программная симуляция. Нет вооружения, наведения, боевой автономии,
реальных драйверов, ROS2-мостов, медицинских вмешательств или самоизменения кода.
Pneuma и Logos — численные метафоры. Результаты не доказывают сознание, душу,
эмпатию или физическую безопасность. Нет LLM и обучения нейросети.

## Быстрый запуск

Python 3.10+, внешние runtime-зависимости не требуются.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests -v
humancore --cycles 3000 --seed 42 --out runs/demo
```

Windows PowerShell: вместо source используйте `.venv\Scripts\Activate.ps1`.
Без установки: задайте `PYTHONPATH=src` и выполните `python -m humancore.cli`.

Результат: report.json, cycles.csv и memory.json. Seed фиксирует сценарии;
время выполнения зависит от среды. В комплекте есть результаты реального
локального прогона на 3000 циклов в evidence/.

## Архитектура

Предложение Action + Context → FormalEthicalVeto → решение → математическая
кинематика → журнал. Вето встроено непосредственно в cycle()/breathe().
Неизвестные действия блокируются; NaN, бесконечности и некорректные значения
отклоняются. Препятствие, низкий заряд и аварийный стоп блокируют движение.
При человеке поблизости скорость ограничивается. Это правила модели, не
сертифицированные пределы для реального робота.

- core.py: цикл состояния, вычислительные индикаторы, встроенный veto.
- safety.py: явный allowlist и детерминированные проверки.
- memory.py: SHA-256-цепочка в памяти, копирование записей.
- twin.py: шесть логических сценариев, пакетный прогон, дифференциальная кинематика.
- cli.py: экспорт JSON и CSV.
- tests/: unit-тесты и воспроизводимость.
- .github/workflows/: шаблон CI; его удалённый запуск здесь не проверялся.

## Ограничения безопасности и памяти

Название FormalEthicalVeto сохранено для совместимости терминологии. Формального
доказательства корректности нет. Текстовый контекст не анализируется на смысл;
политика проверяет структурированные действия. Python-объекты не создают
защищённый периметр от недоверенного кода. Хеш-цепочка выявляет локальные
изменения, но не защищает от полного пересоздания журнала. Для доверенного
аудита нужны отдельные подписи и внешний якорь. Память растёт линейно;
ограничение CLI — 100000 циклов. При переданном существующем kernel его история
и состояние сохраняются между пакетными прогонами.

Симулятор не моделирует контакт, динамику, сенсоры, людей и столкновения.
Данные сценариев синтетические. Параметры колёс — демонстрационные.

## Репозиторий

В ZIP включены исходники, локальная история Git и Git bundle.
Репозиторий не опубликован в GitHub/GitLab. Восстановление отдельного клона:

```bash
git clone humancore-stalion.bundle humancore-stalion
```

Вложенный bundle лежит рядом с README. При распаковке уже можно работать
в каталоге проекта как в обычном локальном Git-репозитории.
